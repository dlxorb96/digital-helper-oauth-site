개인용 도구 이용 안내

digital-helper는 운영자가 자신의 계정과 PC에서 이용하는 개인용 블로그 작업 도구입니다. 이 페이지는 기능과 운영 조건을 설명합니다.

계정과 사용 범위

운영자 본인의 Google 계정과 네이버 블로그 권한 범위에서 이용합니다. 이 공개 사이트는 앱 소개와 정책 안내를 제공합니다.

검토와 발행

메일 첫 줄의 승인·수정·중단 지시를 현재 글 버전과 대조합니다. 초기 10편에는 글별 명시적 승인이 필요하고, 이후 운영 모드 변경에는 별도 시작 확인이 필요합니다. 수정한 글은 새 승인을 받습니다. 예약·발행 이후의 수정·중단 요청은 운영자에게 알립니다.

동작 조건

메일 확인과 화면 작업에는 운영자 PC, 프로그램 및 필요한 로그인 세션이 실행 중이어야 합니다. 네트워크, 인증 만료와 외부 서비스 화면 변경에 따라 작업이 보류될 수 있습니다. 예약 등록과 실제 공개 결과는 외부 화면에서 확인합니다.

본문과 이미지 검토

생성한 안내에는 오류가 있을 수 있으므로 출처와 실제 화면을 확인하고 검토합니다. 게시 이미지에서 개인 정보가 노출되지 않는지 확인합니다. 운영자는 작성물의 내용과 게시 여부를 결정합니다.

데이터 관리

Gmail 데이터의 접근·처리·보관 및 연결 해제는 개인정보처리방침을 따릅니다. 필요한 작업 기록의 보관·삭제와 계정 연결 상태는 운영자가 관리합니다.

비용과 문의

이 공개 안내 사이트에서 요금을 청구하거나 결제 정보를 받지 않습니다. 도구가 이용하는 외부 서비스의 계정·요금·정책은 해당 서비스의 조건을 따릅니다. 문의는 GitHub 저장소 문의 창을 이용해 주세요.
