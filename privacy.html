개인정보처리방침

이 방침은 운영자 GitHub @dlxorb96의 개인용 도구 digital-helper가 처리하는 Google 계정 정보와 작업 기록을 설명합니다.

1. 접근하는 정보와 권한

연결된 Gmail 계정 주소, 검토·알림 메일 및 관련 답장의 제목, 발신자, 수신·발송 시각, 본문, 메시지·스레드 식별자와 라벨 정보를 처리합니다. 인증 과정에서 OAuth 접근 토큰과 갱신 토큰을 받습니다.

요청하는 권한은 Gmail 읽기(gmail.readonly)와 메일 발송(gmail.send)입니다. 읽기 권한은 메일함에 대한 접근 권한이지만 프로그램은 검토 답장 및 발송 기록 확인에 사용합니다.

2. 이용 목적

현재 글 버전의 승인·수정·중단 확인, 수정본 검토 요청, 예약 및 발행 상태 확인, 오류·확인 알림과 주간 보고에 이용합니다. 같은 답장을 반복 처리하거나 같은 검토 메일을 중복 발송하지 않도록 식별자와 처리 기록을 보관합니다.

3. 저장과 보관

작업 기록은 운영자 PC의 프로젝트 자료 폴더에 저장합니다. 검토 메일 기록, 답장, 최종 본문·이미지·버전과 발행 증거는 운영자가 삭제할 때까지 보관합니다. 중간 작업물은 30일 보관 정책을 적용합니다. 프로그램 실행 로그는 운영자가 삭제할 때까지 보관합니다.

Windows 인증 토큰은 해당 Windows 사용자에게 연결된 DPAPI 암호화로 저장합니다. 메일·본문·작업 기록 전체가 같은 방식으로 암호화되는 것은 아닙니다. OneDrive 등 동기화 폴더에 설치한 경우 해당 동기화 설정에 따라 파일이 동기화될 수 있습니다.

4. 외부 서비스 처리

Gmail 송수신은 Google 서비스에서 처리합니다. 글 작성과 수정에 필요한 답장의 수정 지시와 관련 블로그 자료는 사용자가 요청한 기능을 수행하기 위해 Codex/OpenAI 서비스에 전달될 수 있습니다. 승인·중단 상태 처리는 로컬 프로그램에서 수행합니다. 블로그에 공개하는 대상은 승인된 본문과 게시용 이미지입니다.

Google API로 받은 정보는 위에 설명한 사용자 기능에 한정해 이용하며 광고 타기팅, 데이터 판매나 데이터 중개를 목적으로 이용하지 않습니다. digital-helper의 Google API 정보 이용과 다른 앱으로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다.

5. 연결 해제와 기록 삭제

운영자는 Google 계정의 서드 파티 연결 관리에서 앱 권한을 취소할 수 있습니다. 권한 취소는 이미 보관한 로컬 기록의 삭제와 별개입니다. 기록을 삭제하려면 프로그램 실행을 멈춘 뒤 PC의 해당 자료와 동기화 사본을 직접 관리해야 합니다.

6. 이 공개 안내 사이트

이 사이트 자체에는 입력 양식, 분석 스크립트 또는 로그인 기능이 없습니다. GitHub Pages는 보안 목적으로 방문자의 IP 주소를 기록합니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

7. 문의와 변경

문의는 이 사이트의 GitHub 저장소 문의 창을 이용할 수 있습니다. 공개 문의에 메일 본문, 인증 코드나 토큰 등 개인 정보를 게시하지 마세요. 처리 목적이나 데이터 범위를 변경할 때는 방침을 갱신하고 필요한 동의를 다시 받습니다.
